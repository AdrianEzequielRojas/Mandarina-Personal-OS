# Producto

Mandarina Personal OS organiza la vida cotidiana alrededor de una pantalla de inicio accionable. La prioridad es reducir fricción: mostrar lo necesario para el día y permitir una carga rápida desde el celular.

## Áreas principales

- **Inicio:** resumen de dinero disponible, actividad reciente, menú del día y accesos rápidos.
- **Finanzas:** ingresos, gastos, cuentas, categorías, presupuestos y objetivos.
- **Casa:** tareas, mantenimiento y organización doméstica.
- **Menú:** planificación semanal de comidas.
- **Estilo de vida:** rutinas y seguimiento personal.
- **Configuración:** preferencias, perfil y controles de la cuenta.

## Criterios de experiencia

- Mobile-first para la carga diaria.
- Información resumida antes que tablas extensas.
- Modales cortos para las acciones frecuentes.
- Indicaciones cercanas al campo cuando una validación falla.
- Estados claros para carga, ausencia de datos, error y éxito.
